# NeoForge 1.21.1 port

This directory contains only the NeoForge Gradle scaffold and shared,
loader-independent sources. Platform code and the Iron's Spellbooks dependency
must be added as part of the port.

Requirements:

- Java 21
- NeoForge 21.1.244
- Gradle wrapper 9.2.1

Build with `gradlew build` from this directory, or with
`gradlew buildNeoForge` from the repository root.
